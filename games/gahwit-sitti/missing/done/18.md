# 18 · Live events, daily systems and remote config

**Status (2026-10-31):** remote config, the daily gift, daily tasks, the event framework, the mini board and the double weekend are built and tested on both sides. Staff publish a config or schedule a mini board on the platform and the game picks it up without an update. The pass, the album and hosting wait for their content (02, 11, 13) and social features (20); the admin panel's screens for this are 22.

**Ring 2 · Size L · Spec:** `GAME_SYSTEMS.md` 13, 14, 16; `SYSTEMS_B.md` 9; `balance.json` `events`, `dailyLogin` and `dailyTasks`; `COMPLETE_SPEC.md` 2

## Where it stands

- Nothing is built in the game.
- The server has `/config` and `/events` routes on PostgreSQL, but no way for staff to publish a config or schedule an event.
- The save keeps `events` and `daily` sections but doesn't use them.
- The game reads only its bundled copy of `balance.json`. Nothing overrides it remotely.
