# 16 · Analytics and crash reporting

**Ring 1 · Size S–M · Backlog 22 · Spec:** `GAME_SYSTEMS.md` 15, 16; `COMPLETE_SPEC.md` 1, 17; `PLAN.md` 2 (gates)

## Where it stands

- No analytics SDK, no events and no crash reporting.
- The ring 1 gate test and the soft-launch gates both depend on this data.

## What's missing

**Choose the tools**
- **Analytics:** Firebase or GameAnalytics (`GAME_SYSTEMS.md` 16).
  - Firebase also brings Crashlytics, and the Cloud Messaging that hosting needs (19), in one SDK.
- **Attribution for paid installs.** Nothing in the specs covers it yet. The soft-launch gate "ad spend pays back within 12 months" (`PLAN.md` 2) needs a way to tell which ad brought a player.

**Code**
- An `IAnalytics` interface in Core, with a fake for tests. The SDK sits behind it.
- No game rule calls the SDK directly.

**Events** (`GAME_SYSTEMS.md` 15)

| Event | Fields | Fired from |
|---|---|---|
| `session_start`, `session_end` | Length, energy at start | Boot, pause |
| `tutorial_step` | Step id | Tutorial (06) |
| `generator_tap` | Generator, level, energy left | `Game.TapGenerator` |
| `merge` | Chain, new level, bubble shown | `Game.Move` |
| `order_served` | Chain, item level, coins, character | `Game.Serve` |
| `task_complete` | Chapter, task, style chosen | `Game.CompleteTask` |
| `scene_viewed`, `scene_skipped` | Scene id, seconds | Dialogue |
| `level_up` | New level | `Game.AddXp` |
| `energy_empty` | Time since session start | Kitchen |
| `ad_offer`, `ad_watched` | Placement | Ads (17) |
| `store_view`, `purchase` | Product, price tier, country | Shop (17) |
| `event_join`, `event_progress` | Event id, milestone | Events (18) |
| `board_full` | Free squares | Kitchen |

**Metrics to watch from day one** (`COMPLETE_SPEC.md` 17)
- Tutorial completion by step, and first-session length.
- The share of players who reach the first memory.
- Day 1 return by country.
- Energy-empty moments per session.
- When the first purchase happens.
- Rewarded ads per daily player.
- Crash-free users (target 99.5%+).

**Dashboards**
- Soft-launch gates: day 1, 7 and 30 retention, payer conversion, ARPDAU and ad payback.
- The ring 1 gate test: who finished the tutorial, who reached the letter, session lengths.

**Consent and privacy**
- Under 13 or age unknown: no personalised ads (04).
- If ads or attribution use the advertising id on iOS, the game must show Apple's tracking prompt (App Tracking Transparency).
- The store privacy forms must list exactly what these SDKs collect (21).

## Done when

- Every event in the table shows up in the dashboard from a test build (backlog 22).
- A test crash from a test build appears in the crash tool.
- The soft-launch dashboard shows the `PLAN.md` gate numbers.
