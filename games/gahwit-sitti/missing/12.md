## Where it stands

- **The memory framework works.** It plays a scene today, fades to 1974, then plays an intro, the game, a scene for the result and an outro, and returns to today. A memory cut short resumes on the next launch.
- **The pour game** has 5 tests (`_Game/Memories/PourGame.cs`).
- **Every other type is skipped.** `GameBootstrap.PlayMemory` logs a warning for any type that isn't pour.
- **The easy assist** is built but always off, because there's no settings field for it.
