# 22 · Admin panel

**Ring 2 (support, config, purchases) · Ring 3 (events, moderation) · Size L · Spec:** `/platform/README.md` ("Staff", "Admin panel"); `COMPLETE_SPEC.md` 16; `BUILD_GUIDE.md` 8

## Where it stands

**The staff API exists** (`platform/src/Platform.Api/Admin/`), tested:
- staff sign-in, password change, and a `create-owner` command
- roles per game: owner, producer, support, viewer
- player search and detail, and grants to a player
- support tickets: list and close
- staff management and an audit log

**There's no web app on top of it yet.** The README says "to come".

## What's missing

**The web app**
- **Choose** the stack: Blazor inside the platform, or a separate web app on the staff API.
- Add two-factor sign-in for staff.

**Pages on the existing API**
- Players: search, detail, save summary, flags from the save check, purchases, wallet.
- Grants, with a reason, shown in the audit log.
- Support inbox.
- Staff and roles.
- Audit log.

**Pages that also need new API routes**

## Done when

- Support can find a player from a ticket in the browser and grant compensation, and the grant shows in the audit log.
- A producer can publish a new `balance.json` and schedule an event without a developer.
